# Кольори чеків за маркетплейсом — 1.0.53

Таблиці «Усі чеки» та «Чеки та замовлення» використовують спільний стиль рядка. Кольори відповідають таблиці замовлень:

| Зв’язане замовлення | До друку | Після друку чека |
| --- | --- | --- |
| Prom | `#EDF5FF` | `#BFDAFA` |
| Rozetka | `#EFFAF2` | `#BCE8C9` |
| Немає зв’язку | білий | білий |

Колір визначається пов’язаним замовленням для точного, ручного або автоматичного зв’язку. Список кандидатів, конфлікт чи неповна перевірка не забарвлюють чек. Назва способу оплати та перевізник не визначають маркетплейс.

Стару підсвітку за типом чека й загальну зелену підсвітку надрукованих чеків замінено. Чек без зв’язку залишається звичайним незалежно від типу та локальної історії друку. Статус друку й повідомлення про помилку доступні у своїх полях/підказках.

Переприв’язка чи зняття зв’язку оновлює колір одразу через сповіщення `LinkedMarketplace`; зміна статусу друку використовує наявне сповіщення `PrintStatus`. Числові суми зберігають єдиний жирний шрифт для всіх рядків. Активне виділення комірки й виділення тексту працюють як раніше.

Візуально перевірено обидві скомпільовані таблиці на синтетичних точних, ручних та автоматичних зв’язках, звичайних і надрукованих рядках, непов’язаних продажах/поверненнях/службових чеках, кандидатах і конфліктах. Переприв’язка, зняття зв’язку та зміна статусу друку оновлюють палітру без перезавантаження. Наявна перевірка неактивного виділення в обох таблицях пройшла з новою палітрою.
