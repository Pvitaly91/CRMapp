# Прокрутка таблиць — 1.0.72

Клітинки CRMapp містять інтерактивні редактори DashboardTextBox для виділення й копіювання частини тексту, кнопки перегляду, чеки та статуси відправлень. Раніше при перетягуванні повзунка WPF перебудовував видиму область на кожній проміжній позиції, навантажуючи потік інтерфейсу.

Для чотирьох головних таблиць увімкнено відкладене прокручування: повзунок рухається одразу, вміст переходить до кінцевої позиції після відпускання. Звичайна прокрутка стрілками, коліщатком і програмний перехід до конкретного рядка лишаються негайними. Рядки віртуалізуються з повторним використанням контейнерів. Стовпці кешуються, щоб не створювати заново важкі редактори при кожному горизонтальному русі.

Варіант із віртуалізацією стовпців перевірено й відхилено: він зменшував кількість клітинок, але створення нових редакторів і зміна висоти рядків давали додаткові затримки. У контрольному порівнянні з однаковою висотою рядків 13 позицій займали 15–45 мс з кешованими стовпцями проти 107–580 мс із їх віртуалізацією. Це діагностика конкретного середовища, а не гарантія часу на інших комп’ютерах. Додаткову фіксацію висоти рядків не застосовано: кілька чеків і багаторядкові статуси й далі визначають її автоматично.

Ізольований тест використовує чотири справжні скомпільовані XAML-таблиці та по 1000 штучних рядків. Він перевіряє проміжні й кінцеві позиції відкладеного прокручування, обмежену кількість створених рядків, правильний текст після переходу до далекого рядка та повернення, сортування й незалежні галочки. Час виводиться лише як діагностика; автоматичні перевірки не залежать від швидкості процесора. Реальні API, облікові дані та фізичний друк не використовуються.
