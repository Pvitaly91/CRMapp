# Видимий стан ключів і облікових даних — 09.10.2026

Версія 1.0.28 додає індикатори для Checkbox, Prom, Rozetka Seller, Нової пошти та Rozetka Delivery. Зелений означає наявність локально збереженого ключа/повних облікових даних. Помаранчевий — введений чи відкладений при перемиканні магазину новий секрет, який ще не збережено. Сірий — відсутність налаштувань, завантаження або неможливість прочитати стан. Відсутність видимого тексту в PasswordBox не визначає збережений стан.

Checkbox використовує чинну ознаку збережених облікових даних. Маркетплейси читають стан лише вибраного підключення з локального secret store; в окремій моделі статусу зберігається тільки bool. При перемиканні магазинів статус обчислюється для поточного ID, а секрети не переносяться між полями. Нова пошта використовує актуальну збережену прив’язку ключа до вибраного магазину. Статуси Rozetka Delivery та Seller показані також при згорнутих розширених параметрах доставки. Перевірка накладної показує стан чинного NP-ключа.

Статус не перевіряє мережеві права або валідність ключа на сервері. Кнопки перевірки API залишаються окремими. Відкриття статусу не зберігає налаштування й не запускає друк. Ключі/паролі не показуються, зокрема у підписах, знімках та повідомленнях помилки.

Перевірки: збережений Prom-токен при порожньому полі, повні/неповні дані Rozetka, відкладений draft після перемикання магазину та збереження, Checkbox, NP-прив’язки різних магазинів, RD-токен, Seller, відсутність секретів у текстах UI. Індикатори у скомпільованому XAML збережено як синтетичні PNG і візуально перевірено. API та фізичний принтер під час тестів не викликаються.

Завершені перевірки: 372/372 тестів, exit code 0.
