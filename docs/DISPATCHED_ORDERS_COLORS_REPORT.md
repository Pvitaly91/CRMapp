# Підсвітка переданих перевізнику замовлень — 1.0.56

Таблиця замовлень має три відтінки кожного маркетплейсу: початковий Prom `#EDF5FF` / Rozetka `#EFFAF2`, надруковані накладні `#BFDAFA` / `#BCE8C9`, підтверджене передавання перевізнику `#8CB9EB` / `#85CDA0`. Остання ознака має вищий пріоритет за друк, незалежно від наявності локальної історії. Скасоване замовлення завжди залишається червонуватим `#FDE8E7`.

`ShipmentTrackingProgress` розпізнає відомі назви фактичного приймання, руху, прибуття й видачі за поточним трекінгом саме цієї ТТН. Для Rozetka використано [відкритий довідник статусів](https://rz-delivery.rozetka.ua/api/track-status) і [офіційний Swagger](https://rz-delivery.rozetka.ua/api/docs/), прочитані 14.10.2026: «Прийнято на доставку», «Прийнято перевізником», «В дорозі до РЦ», «Посилка отримана на РЦ», «У дорозі з РЦ», «Відправлення у відділенні», «Готово до видачі», «Видано». Для НП підтримано поточні назви приймання, руху до міста/відділення, прибуття, передавання кур’єру та отримання. Неоднозначна назва «На проміжному РЦ» присутня у прямому й зворотному потоках Rozetka; тільки за цим текстом передавання не визначається.

Підготовка, очікування, створення ЕН, невідомий/недоступний статус, заперечення, відмова та повернення не дають нової ознаки. Якщо ТТН кілька, потрібне підтвердження для кожної; непідтверджена ТТН не успадковує стан сусідньої. Старий статус, який UI вже показує після мережевої помилки, зберігає відповідний відтінок; підказка ТТН продовжує повідомляти про застарілість. Заміна номера/ідентифікатора накладної або акаунта прибирає чужий стан. Оновлення статусу одразу повідомляє WPF про зміну кольору.

Це лише оформлення замовлень. Статус друку, історія, відбір кандидатів, галочки та зв’язки чеків не отримують нових значень. Нових запитів до API чи змін кешованого замовлення немає; використано вже завантажений трекінг. Таблиці чеків і незалежних накладних не змінені.

Перевірка розширює наявний ізольований WPF/XAML сценарій: шість відтінків, оновлення кольору після нового статусу, негативний статус після позитивного, кілька ТТН, заміна ТТН/акаунта, скасоване замовлення поверх ознак друку й доставки, відсутність запису історії та друку. Release Development: **602/602** перевірки пройдено; лише попереднє попередження WFAC010. Синтетичне зображення `shipment-dispatch-colors.png`, створене через `CHECKBOX_TEST_RENDER_DIR`, переглянуто: усі три сині й зелені відтінки відрізняються, текст читається. Підсумок production-збірки й встановлення підтверджується метаданими готового пакета, а не цим описом.
