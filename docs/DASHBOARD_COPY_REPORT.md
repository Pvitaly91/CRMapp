# Виділення й копіювання клітинок — 09.10.2026

Версія 1.0.29 прибирає дубльовані кнопки «Налаштування маркетплейсів» і «Налаштування наклейок» із панелі замовлень. Загальне вікно налаштувань із відповідними вкладками залишається.

У таблицях замовлень та обох вкладок чеків увімкнено Extended/CellOrRowHeader. Ctrl+C і меню «Копіювати» передають виділені значення у буфер обміну; кілька клітинок формуються як TSV у поточному порядку рядків і колонок. Шаблонні колонки мають явні текстові значення для номера рядка, чеків, ТТН та номера замовлення. Дані не копіюються як зображення кнопок. Права кнопка вибирає нову клітинку, якщо вона не входить до поточного діапазону.

Ctrl+A усередині таблиці виділяє всі її клітинки; звичайні поля тексту зберігають власні клавіші копіювання/виділення. Галочки друку незалежні від клітинок і залишаються під керуванням старих кнопок/checkbox. Поточна клітинка зберігає логічний вибір чека/замовлення для перегляду та ручної прив’язки; він не обмежує копійований діапазон.

Скомпільований XAML перевіряє відсутність кнопок, доступність загальних налаштувань, багатоклітинкове виділення, формування тексту замовлень у відсортованому порядку, ТТН та фіскального номера, незмінні галочки друку та збереження вибору для прив’язки. Тести читають готовий текст без перезапису реального буфера обміну, API чи фізичного друку.

Повний набір: 372/372 тестів, exit code 0. Вигляд нової панелі збережено та візуально перевірено.
