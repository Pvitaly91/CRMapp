# Перемикачі вибору в заголовках — 10.10.2026

Версія 1.0.34 прибирає повторювані кнопки «Виділити всі»/«Зняти всі», а також «Вибрати видимі для наклейок»/«Зняти вибір наклейок». У першій колонці чотирьох таблиць є один перемикач масового вибору: усі чеки, чеки замовлень, замовлення для наклейок і всі накладні.

Стан відображає вибір: порожній, повний або проміжний. Порожній/частковий вибір доповнюється до всіх доступних видимих рядків; повний вибір знімає всі галочки цього дашборду, включно з прихованими, як колишня кнопка очищення. Коли видимих доступних рядків немає, але приховані галочки є, перемикач дозволяє їх зняти. Порожня таблиця без галочок не має активної дії. Замовлення без ТТН і видалені накладні не входять у масовий вибір.

Перемикачі двох списків чеків незалежні, як їхні попередні кнопки. Це галочки друку, а не виділення клітинок чи фрагментів тексту. Стани оновлюються після ручного вибору, пошуку/дат/фільтрів, зміни рядків і після успішного друку. Відповідні операції завантаження/друку блокують масовий вибір. Підпис «№» та нумерація рядків збережені.

Об’єкти Header колонок можуть перебувати поза візуальним деревом таблиці. Їхні прив’язки створюються після InitializeComponent із прямим посиланням на власне вікно, щоб приховані й повторно показані вкладки не втрачали правильний ViewModel. Нові підписки на рядки від’єднуються при видаленні/скиданні та Dispose.

Перевірено 448/448 тестів. Нові 11 STA сценаріїв охоплюють часткові/приховані галочки, незалежні вкладки, фільтри й сортування, зміну ТТН, скасовані/видалені рядки, зайнятість та fake передавання друку. Скомпільований XAML перевіряє кліки всіх чотирьох заголовків і відсутність старих кнопок; вигляд таблиць перевірено на синтетичних даних. Реальний принтер і API під час цих перевірок не використовувались.
