# Виділення фрагментів тексту — 09.10.2026

Версія 1.0.31 замінює текстові відображення колонок у таблицях чеків, замовлень і накладних на `DashboardTextColumn`: значення показує прозорий `DashboardTextBox` лише для читання. Нативний TextBox підтримує позиціювання курсора, перетягування фрагмента, подвійний клік для слова, Ctrl+C і контекстне меню. Відображення не записує зміни в модель; зберігаються форматування, сортування, кольори та механізм копіювання клітинок.

Шаблонні номери рядків, ТТН і номери пов’язаних замовлень також підтримують виділення. Простий клік по номеру з командою відкриває той самий документ після системного інтервалу подвійного кліку. Перетягування, виділений текст, другий клік, зміна параметра/рядка, втрата фокуса або вивантаження клітинки скасовують відкладений перегляд. Так вибір фрагмента не відкриває наклейку чи замовлення.

Під час роботи з текстом команди копіювання таблиці й подвійний клік перегляду чека поступаються нативним діям текстового поля. Поточна клітинка синхронізується з вибором чека/замовлення для ручної прив’язки; галочки друку не змінюються.

Перевірки: форматовані дата та сума, односторонні прив’язки, фрагмент і доступність нативної Copy без перезапису буфера користувача, всі чотири таблиці у скомпільованому XAML, відсутність помилок прив’язок, відкладені дії та скасування застарілого перегляду після повторного використання контейнера. Реальні API й фізичний друк не потрібні.

Повний набір: 402/402 тестів, exit code 0. Окремий тест справжнього DataGrid перехоплює `DataObject.Copying` і скасовує запис буфера після перевірки, що payload містить лише вибраний фрагмент. Скомпільовані таблиці візуально перевірені; форматування та кольори рядків збережено.
