# Кольори рядків зберігаються після втрати фокуса — 08.10.2026

Версія 1.0.27 прибирає сірий фон стандартного неактивного виділення в таблицях замовлень та обох вкладок чеків. Стиль DataGridCell при IsSelected=true та Selector.IsSelectionActive=false бере Background/Foreground з відповідного DataGridRow. Колір статусу друку/маркетплейсу лишається видимим.

SelectedItem, галочки друку, поточний рядок і прив’язки не очищуються. Це дає змогу вибрати замовлення, перейти до чека й підтвердити ручний зв’язок. Активне виділення не перевизначається. Логіка друку та журналу не змінена.

У скомпільованому XAML перевірено вибрані клітинки надрукованих Prom/Rozetka, звичайного замовлення та надрукованого чека в обох вкладках. Клітинки зберігають кольори рядка, вибір моделі залишається. Перевірки використовують синтетичні дані без реальних API та друку.
