# Пошук чеків за ID та сумою — 1.0.54

Наявне поле «Пошук» у таблицях чеків знаходить завантажені чеки за ID (повним UUID або його частиною) та точною сумою у гривнях. Номер чека, фіскальний номер, оплата, каса й тип документа також залишаються доступними для пошуку.

Для суми 1200 грн приймаються `1200`, `1200.00`, `1200,00`, `1 200`, `1 200,00`, `1,200.00` і `1.200,00`. Підтримано звичайні й нерозривні пробіли групування. Значення порівнюються точно, із копійками, незалежно від регіональних налаштувань Windows. Сума 1200 не підбирає 12000 або 1200,10 лише через частковий збіг суми. Інші поля документа продовжують шукатися за частиною тексту.

Сума розбирається один раз при зміні пошуку. Невідомі суми не прирівнюються до нуля. Помилкове групування, переповнення, експоненційний запис або більше двох знаків копійок не стають сумою для пошуку.

Пошук локальний: нових запитів до сервісів немає. Він поєднується з наявними датами й типом чека; приховані галочки зберігаються, на друк потрапляють лише видимі позначені рядки активної таблиці. Стани пошуку різних вкладок залишаються незалежними.

Пройшли 595/595 тести. Нові перевірки охоплюють точність копійок, формати української та англійської локалі, повний і частковий UUID, помилкові числа й переповнення, невідомі суми, межі дат, тип чека та збереження прихованих галочок після друку видимих рядків. Фізичний друк не запускався.
