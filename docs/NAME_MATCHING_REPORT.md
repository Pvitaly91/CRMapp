## Що змінилося

Після відбору за повною сумою й датою працює наявна перевірка повного кошика та кількості. Для назви додано вузькі правила:

1. Повна нормалізована назва й кількість підтверджують товарний збіг. Прості перестановки суто літерних слів без прийменників/ролей, наприклад «Червоний кабель USB» / «Кабель USB червоний», також зіставляються. Числа, коди, моделі, роз’єми й ролі input/output, left/right не переставляються й не стираються.
2. Явно різні типи на початку назви можуть дати конкретну підставу виключення: кабель, датчик, електроживлення/роз’єм/розетка, вимикач, резистор, освітлення. Словник обмежений; це не загальний визначник мови чи сервіс перекладу. USB-розетки, роз’єми й зарядні пристрої об’єднані в консервативну групу, щоб синонімічні назви не виключали одна одну.
3. Для визначення типу допускається лише короткий перелік відомих префіксів, наприклад USB, LED, «врізна». Згадки кількох типів, комплекти/тестери/корпуси та невідомий початок назви не дають доказу. Слова всередині іншого слова не розпізнаються як тип.
4. Нерозпізнана, перекладена або скорочена назва — **недостатньо даних**, а не суперечність. Такий конкурент залишається в графі. Точний текст одного кандидата не дозволяє відкинути інший невизначений.

Стара перевірка зіставлених моделі, напруги, розміру, кольору, роз’єму та кількості збережена. SKU різних систем не став спільним ключем. Виключення містить пояснення конкретних типів або характеристик. Суперечність залишкової позиції встановлюється лише щодо всіх можливих залишкових позицій іншого кошика.

Після виключень перевіряється взаємна унікальність у всьому графі, незалежно від видимих фільтрів. Ручні/точні фіскальні рішення зберігають пріоритет. Ймовірний результат не стає фіскальним чи ручним. Для перекладених назв із нерозпізнаною тотожністю лишається `Products=Insufficient`; усунення явно іншого типу може залишити взаємно унікальну суму, але не підвищує її до підтвердженого збігу товарів.
