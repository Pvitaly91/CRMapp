# Перегляд наклейки через номер ТТН — 07.10.2026

Версія 1.0.26 об’єднує номер ТТН і перегляд наклейки в колонці «ТТН». Колонка «Етикетка» та окрема кнопка «Перегляд наклейки» прибрані. Для кожної непорожньої накладної показується своє посилання. Воно передає рядок замовлення та конкретне відправлення в команду перегляду; проміжний вибір між кількома накладними не потрібен.

Перед завантаженням перевіряється, що вибрана накладна ще належить актуальному замовленню. Якщо її замінено, старе посилання не викликає джерело. Перегляд готує лише вибрану наклейку; друк, журнал передавання, галочки й історія чеків не змінюються. Попередня команда перегляду замовлення залишається для інших викликів.

Підтверджено на синтетичних даних: конкретна друга накладна відкривається без chooser, змінений номер відхиляється, без ТТН посилань немає. У скомпільованому XAML перевірено текст посилання, команду та її параметр, завантаження саме вибраного документа й відсутність друку. Знімок таблиці з посиланнями збережено та візуально перевірено.

Повний набір: 369/369 тестів, exit code 0. Реальні API та фізичний принтер не викликалися.
